# Upgrade

Regardless of Build Method, you can only upgrade (build a newer version or different feature branch) or update (build the same version) if you have a valid Apple Developer account.

* Sign your developer agreements promptly

Other tasks required to upgrade to the latest version, or to rebuild to keep *Trio* working on your phone, depend on your build method.
