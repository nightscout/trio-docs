# LoopFollow

*LoopFollow* is an open-source DIY (do-it-yourself) app that displays information for a person with diabetes in an easy-to-use interface. It combines information from multiple other apps and provides custom alerts. It runs on iPhone, iPad or Mac devices. Some remote control features are available for the *Loop* and *Trio* apps to assist caregivers.

*LoopFollow* was created because using different apps as a parent or caregiver of a person with diabetes can be cumbersome. Add in the extra details from looping with an Open Source Automated Insulin Delivery (OS-AID) app and flipping back and forth between various sources of information can be a challenge. Many loopers use LoopFollow for themselves because of the flexible (and loud) alarm options.

*LoopFollow* works best when paired with *Nightscout*.

For more information, please refer to the [LoopFollowDocs](https://loopfollowdocs.org).
